## 二、单通道详细电路

### 方案1：电阻分压方案（推荐）

```
                    ┌─────────────────┐
                    │   STM32H750     │
                    │                 │
  电池电压 ───R1──┬──│ PA0 (ADC_INP16) │
  (0~4.2V)       │  │                 │
                 │  │ VREF+ ──3.3V───│── REF3033 (3.3V精密基准)
                 │  │                 │      │
                 R2  │                 │      │
                 │   │                 │      │
                GND  └─────────────────┘      │
                 │                             │
                GND ───────────────────────────┘
```

### 元器件参数

| 元器件 | 规格 | 说明 |
|--------|------|------|
| R1 | 10kΩ ±0.1% | 金属膜电阻，0603/0805 |
| R2 | 10kΩ ±0.1% | 金属膜电阻，0603/0805 |
| C1 | 100nF | 滤波电容，0603，MLCC |
| REF | REF3033 | 3.3V精密基准，0.2%精度 |

### 分压计算

```
输入电压: 0 ~ 4.2V (锂电池)
分压比: R2 / (R1 + R2) = 10k / (10k + 10k) = 0.5
输出电压: 0 ~ 2.1V (进入ADC)

ADC满量程: 3.3V (REF3033提供)
ADC分辨率: 16位 = 65536 LSB
LSB大小: 3.3V / 65536 = 50.4 μV

最小分辨率: 2.1V / 65536 = 32 μV
满足0.05%: 4.2V × 0.0005 = 2.1mV → 2.1mV / 32μV = 66 LSB ✓
```

### 2. 布线要点

| 要点 | 说明 |
|------|------|
| 模拟地 | 单独划分模拟地区域，与数字地单点连接 |
| VREF引脚 | 尽量短且粗，减少噪声 |
| 滤波电容 | 每个ADC通道加100nF电容，尽量靠近引脚 |
| 走线 | 模拟信号走线要短，避免绕长线 |
| 铺铜 | 模拟区域铺铜要完整，减少干扰 |

## 七、软件配置建议

### ADC配置优化

```c
// 推荐配置
hadc1.Init.Resolution = ADC_RESOLUTION_16B;      // 16位
hadc1.Init.SamplingTime = ADC_SAMPLETIME_16CYCLES_5; // 统一采样时间
hadc1.Init.ContinuousConvMode = ENABLE;         // 连续转换
hadc1.Init.EOCSelection = ADC_EOC_SEQ_CONV;     // 序列结束标志

// DMA配置
hadc1.Init.ConversionDataManagement = ADC_CONVERSIONDATA_DMA_CIRCULAR;

// 过采样（可选，提高精度）
hadc1.Init.OversamplingMode = ENABLE;
hadc1.Init.Oversampling.Ratio = 16;              // 16倍过采样
```

### 数据处理建议

```c
// 滑动平均滤波
#define FILTER_SIZE 64
uint32_t adc_filter_buffer[14] = {0};

void ADC_Filter(void)
{
    for(int i = 0; i < 14; i++)
    {
        adc_filter_buffer[i] = (adc_filter_buffer[i] * (FILTER_SIZE - 1) + adc_values[i]) / FILTER_SIZE;
    }
}
```
